# Company website

Single-page company website built with Vite, React, TypeScript, and Tailwind CSS.

## Sections

- Header / navigation (same-page scroll)
- Hero
- Company introduction
- Products / Platform (Educore)
- How we work
- Team wall
- Contact (prototype form)
- Footer

## Placeholders

Editable values live in `src/data/site.ts`:

- `COMPANY_NAME`
- `LEGAL_ENTITY_NAME`
- `TEAM_MEMBERS`

Replace bracketed placeholders with confirmed information before publishing.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```
